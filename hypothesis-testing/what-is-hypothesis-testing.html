What is Hypothesis Testing?

The end-to-end framework for deciding whether an observed difference is real.

by Joshua Osborne

Contents

We perform hypothesis testing when we want to decide whether what we observed in an experiment is different from what we would expect if we had not changed anything from an original experiment.

For example, say I work at Pinterest and I want to know: if I start including videos into the platform, will it improve user engagement? To do this I split my users into two groups: a control group that gets the platform as it currently is (only pictures), and another group who gets a mix of photos and videos. My hypothesis (referred to as the null hypothesis, often written as \(H_0\)) is that nothing will change, meaning that users will still engage the same amount as they did before. The alternative hypothesis (written \(H_1\)) would be that including videos improves user engagement. Written mathematically:

\[H_0:\mu_{treatment} = \mu_{control}\]

\[H_1:\mu_{treatment} > \mu_{control}\]

Where \(\mu\) is the mean. Your hypothesis test does not necessarily need to be used on the mean, but the mean has nice mathematical properties that make it commonly used (refer to mean properties), however you could use the median, mode, etc.

You may often see the following table when talking about hypothesis testing:

\(H_0\) is True \(H_0\) is False
Reject \(H_0\) Type I error (\(\alpha\)) Correct ✓ (Power: \(1-\beta\))
Fail to reject \(H_0\) Correct ✓ Type II error (\(\beta\))

  • \(\alpha\) (Type I error / false positive): the probability of rejecting \(H_0\) when it is actually true. You set this before the experiment and is typically set to 0.05. It is the rate of false alarms you are willing to tolerate.

  • \(\beta\) (Type II error / false negative): the probability of failing to reject \(H_0\) when it is actually false, i.e. missing a real effect. Commonly set to 0.2.

  • Power (\(1 - \beta\)): the probability of correctly detecting a real effect when one exists. A power of 0.8 means you have an 80% chance of catching a true difference. Power increases with larger sample size and larger effect size.

Once you have decided on your \(H_0\), you should then decide on your \(\alpha\) value, which represents how many false positives you are willing to accept. Another way to think about it is: if we ran an A/A test (meaning the control and treatment group are from an identical population such that \(\mu_{treatment}=\mu_{control}\)) 100 times, we would identify 5 times when we rejected the null (the control and treatment mean are not equal). To define our confidence in rejecting \(H_0\), we say that we reject the null when the p-value is less than alpha:

\[p<\alpha\]

To get the p-value we must first decide on a test-statistic. For the example I will give below, I will use the one-tailed z-test and get the z-statistic in order to get the p-value. You may be asking why the one-tailed test? The answer is that we only care if our experiment raised the number of saved pins.

NOTE: I’ve slightly changed the experiment from what is described up above to avoid a ratio metric as this requires more work and we will go over real world applications and use real world metrics in another Applied Notes

The Data

We measure total pins saved during the experiment for each user.

Control (photos only) Treatment (photos + videos)
Users (n) 10,000 10,000
Mean pins saved (\(\bar{x}\)) 8.2 9.4
Std deviation (s) 3.5 4.0

What You Need to Calculate

Step 1: Calculate the Standard Error (SE)

\[SE = \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}=\sqrt{\frac{3.5^2}{10000} + \frac{4.0^2}{10000}}=0.053\]

Step 2: Calculate the Z-statistic

\[z = \frac{\bar{x}_2 - \bar{x}_1}{SE} = \frac{9.4-8.2}{0.053}=22.64\]

Step 3: Get the P-value

\(p = 1-F(z)\), where \(F\) is the cumulative distribution function

\(p=0.0\)

Step 4: Make a decision

\(p<0.05\), so we can safely reject the null hypothesis. Now in industry you may be asked if you should ship this or not. There is one step left of calculating the confidence intervals. In our case, the CI does not cross zero, so we would likely want to ship this.

The Python code

from math import sqrt
from scipy import stats
std1, std2   = 3.5, 4.0
xbar1, xbar2 = 8.2, 9.4
n1, n2 = 10000, 10000
alpha = 0.05
SE = sqrt(std1**2/n1 + std2**2/n2)
mean_diff = xbar2 - xbar1
z = mean_diff / SE
z_alpha2 = stats.norm.ppf(1 - alpha/2)
p = 1 - stats.norm.cdf(z)
CI = (mean_diff - z_alpha2*SE, mean_diff + z_alpha2*SE)  # confidence interval
if p < alpha:
    print("reject the null")
